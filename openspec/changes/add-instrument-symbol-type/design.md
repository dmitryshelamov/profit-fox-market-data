# Design

## Context

Мотивация — в `proposal.md`. Здесь то, что определяет подход.

- Листинг Bybit — `BybitListedInstrument` (категория, символ, активы, статус, правила, тип контракта, время запуска).
  `BybitSymbolConverter` переводит символы Bybit.Net в листинг и бросает исключение на незнакомый статус или тип
  контракта, чтобы урезанный список не делистинговал инструменты (`Список целиком или ничего`).
- Bybit.Net 7.7.0 (через CryptoClients.Net 5.9.0) даёт у `BybitSpotSymbol` и `BybitLinearInverseSymbol` свойство
  `SymbolType` типа `SymbolType?` со значениями `Innovation`, `Adventure`, `XStocks`, `Stock`, `Etf`, `Commodity`,
  `Forex`. Публичный список Bybit 2026-11-25: у 406 USDT-контрактов linear тип пуст, `innovation` 110, `stock` 248,
  `ETF` 62, `commodity` 4, `forex` 4; у spot — `xstocks` 11, `adventure` 3, остальные пусты.
- Листинг хранится в `bybit_listings` столбцами; синхронизация пишет листинг целиком.

## Goals / Non-Goals

**Goals:**

- Тип Bybit доходит до ответа каталога без потерь и без новых причин для сбоя синхронизации.

**Non-Goals:**

- Решение, что считать «акцией»: это правило `profit-fox` (`add-instrument-kind-filter`, решение 1).
- Отбор инструментов каталога по типу и тип у акций T-Invest.

## Decisions

### 1. Своё перечисление `BybitSymbolType` и `null` для «нет типа»

В домене — `BybitSymbolType` с семью значениями SDK; у листинга `SymbolType` — `BybitSymbolType?`. Конвертер переводит
значение SDK по `switch`, а `null` и любое другое значение — в `null`, без исключения.

Почему не ошибка, как у статуса: статус решает, торгуется ли инструмент, и угаданный статус испортил бы каталог; тип —
подпись, и новый тип Bybit (так появились `ETF` и `forex`) не должен останавливать синхронизацию всех пар. Почему не
сырая строка Bybit: проект хранит коды биржи своими перечислениями, а ответ остаётся стабильным при смене SDK.

### 2. Столбец `symbol_type text NULL`

Миграция добавляет `bybit_listings.symbol_type text NULL` без значения по умолчанию; до первой синхронизации тип у всех
`null`. Значение — имя перечисления (`Stock`), как у `status` и `contract_type`.

### 3. Поле `symbolType` в ответе

`BybitListedInstrumentInternal` получает `SymbolType`, ответ отдаёт его строкой имени перечисления или `null`, как уже
отдаёт `contractType`.

## Risks / Trade-offs

- [SDK бросает или пишет предупреждение на незнакомое значение] → тест конвертера на JSON-ответе Bybit с типом `bond`
  проверяет, что синхронизация проходит (задача 2.2); если SDK бросает — записать в «Открыто» и остановиться.
- [Тип пуст до первой синхронизации после выката] → `profit-fox` считает такие пары «криптой»; синхронизацию linear
  запустить вручную сразу после выката (Migration Plan).

## Migration Plan

1. Выкатить; миграция добавляет столбец.
2. `POST api/instruments/bybit/sync` для linear и spot, либо дождаться фоновой синхронизации; проверить, что у
   `TSLLUSDT` в `GET api/instruments/bybit` `"symbolType": "Stock"`.
3. Откат: прежний код столбец не читает.
